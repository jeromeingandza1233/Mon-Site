# Portfolio Jérôme INGANDZA — V1

## Installation
1. Ouvrir `index.html` dans un navigateur pour tester le site.
2. Remplacer `images/portrait.jpg` par votre photo.
3. Placer votre CV PDF dans `documents/CV-Jerome-Ingandza.pdf`.
4. Dans `index.html`, remplacer :
   - `votre.email@example.com`
   - `https://www.linkedin.com/`
   - les textes de présentation si nécessaire.
5. Envoyer tout le dossier chez votre hébergeur en conservant l'arborescence.

## Fichiers
- `index.html` : structure et contenu
- `style.css` : design, responsive et animations
- `script.js` : menu mobile, année automatique et animations
- `images/portrait.jpg` : emplacement de la photo
- `documents/CV-Jerome-Ingandza.pdf` : emplacement du CV

## Important
Le site utilise Google Fonts via une importation CSS. Si vous voulez un site totalement autonome hors ligne, les polices peuvent être remplacées par des polices système.
